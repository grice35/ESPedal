# ESPedal: An Embedded Multi-Effect Guitar Pedal

# Introduction
The ESPedal is a prototype for an embedded audio controller which was part of an individual final project for the Embedded Systems Design course at Georgia Tech. The goal of this project was to design and prototype an embedded device that incorporated fundamental principles of embedded systems, such as digital and analog I/O, hardware communication protocols, and RTOS functionality such as task scheduling and interrupts. The decision to build a multi-effect pedal came from a desire to improve upon an electronic device that is widely used by electric guitarists for practice settings as well as large concerts. 

# Problem
For many guitarists, one of the main problems with effect pedals comes from having multiple devices with many settings to keep track of while playing. When using a pedal, the audio signal from the guitar acts as the analog input which is routed through multiple passive low pass filter circuits and an op-amp before being trimmed, modulated, or delayed using different configurations of resistors and capacitors. This modified signal is then sent as an analog output to the primary amplifier which boosts the signal and plays audio at the desired volume. Most pedals use 6.35mm stereo sockets for the analog I/O, which accept special cable jacks used for guitars and guitar amps commonly referred to as TS (Tip-Sleeve) connectors. Typically, to have the option of switching between effects applied on the guitar’s audio, a guitarist must daisy-chain many effect pedals together and manually turn each one on or off, resulting in significant equipment overhead and time wasted just to change a couple settings. This problem is important because it affects the way musicians practice and perform on stage, specifically when switching between songs that use different audio effects.

Solution
The most obvious solution to this problem is simple: consolidate all the hardware into a single device that can switch between multiple effects and requires minimal user input. Instead of interfacing with multiple pedals, this new pedal is more reminiscent of a soundboard where all possible inputs exist on one panel and can be changed/adjusted freely with minimal downtime. The final design of the pedal consisted of two main user inputs: one to select the desired audio effect, and the other to toggle the selected effect. The driving philosophy behind designing the pedal in this way was creating a simplified user experience that never distracts the musician from playing their instrument. 

# Approach
The approach used when designing the pedal involved taking a standard RC filter circuit used in most guitar pedals and incorporating a programmable microcontroller (specifically the ESP32) to perform digital signal processing on the input before outputting it to the guitar amp. Stereo jacks were utilized to allow the circuit to both receive audio input from the guitar and send analog output to the amplifier. Having the input and output signals pass through op-amps at the end of the input and output stages helped in both stepping up and stabilizing the voltage before reaching the ESP32’s onboard ADC and then being sent to the larger guitar amplifier. Additionally, two power supply circuits were used to send certain voltages to different parts of the main circuit. One supplies a stable 5V to all the components and the other supplies a virtual ground of 1.5V to the RC filters in the input stage. The simplified user interface consisted of a toggle switch for the power, a 3-in-1 footswitch for effect activation, a pushbutton to cycle between effect modes, and an LCD screen to display the selected mode. The focus of the project was to provide a prototype/proof-of-concept of a working embedded system, so all the implementation and testing was done on breadboards. Testing and verification mainly consisted of plugging the circuit into my electric guitar on the input side and an amplifier on the output side and adjusting the variable resistor that controlled the signal gain to achieve maximal volume and minimal noise in the final modified signal emitted from the amplifier. A multimeter was also used to test voltage and resistance in different parts of the circuit to troubleshoot issues with the filtering.

# Results and Discussion
After a design and testing period of three weeks, the final state of the project that was presented in the live demo was a fully functional prototype of a mixed-signal guitar pedal circuit that could switch between two effects: distortion using analog filtering and bit-crushed using digital compression. The success of this prototype opens the door to adding more effects to a guitar pedal with the ability to easily switch between them in real time. The challenges that arose while working on this project mainly stemmed from the hardware and materials used for the prototype, such as cheap breadboards with loose pinholes that resulted in inconsistent connections between components and parts that could not be installed on a breadboard, which included both the toggle switch and the footswitch. There was also an idea of using BLE to control the pedal remotely that was scrapped early in the design process because it would be an expensive feature both power and memory-wise for a system with limited memory constraints running on a portable power supply. Additionally, this feature would probably be wasted on the average user of this pedal since there is rarely a situation where there would be enough distance between the user and the pedal to warrant using a mobile device to interface with it. Working through these challenges taught me a great deal about analog I/O and digital signal processing in the context of embedded systems, as well as how to debug a system with software drivers that directly control the hardware.

# Next Steps
Some of the broader impacts I foresee the ESPedal having on the industry are a push toward bundling more effects in a single pedal and giving guitarists more control over their sound in real time. A substantial improvement to the microcontroller firmware that I hope either myself or another engineer inspired by this project can one day implement is more advanced DSP algorithms that could potentially allow users to mix multiple effects for a more customizable sound. Next steps for this project include designing a PCB for the system using KiCad and sending it out to a manufacturer to print out the board. This was the last step I had in mind for the project that I unfortunately did not get around to during the Fall 2025 semester, so once I have the printed board in my hand with all the components soldered, I will be able to finally consider the ESPedal a finished product and the project complete for now.
